# DevLinks

Página de perfil com lista de links inspirada no Linktree, construída com React, Vite e TypeScript.

As instruções para o desenvolvimento assistido — incluindo referências, design system e o plano de implementação em fases — estão no arquivo [AGENTS.md](./AGENTS.md).

## Como executar

```bash
npm install
npm run dev
```

## Scripts disponíveis

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera o build de produção (inclui checagem de TypeScript).
- `npm run preview`: pré-visualiza o build de produção.
- `npm run lint`: executa o linter (oxlint).
